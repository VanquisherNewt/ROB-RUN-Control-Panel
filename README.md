A panel-first build. The menu is the product: search, pins, themes, keybind editor, profile export.

## Panel

- instant option search
- pin up to 8 options
- three profiles, F6 switch
- dark and contrast themes
- keybind editor with conflict check
- plain text export / import

Modules: aim, visuals, radar, misc, all optional.

## Install

Admin loader, game, INSERT opens the panel, F6 switches profiles.

## Troubleshooting

Panel hidden: admin rights. Pins lost: import the export. Search empty: clear field.
